THABO GAME – Retro Snake System

THABO GAME is a classic Snake game developed by Thabo Seshoka as a programming project and a way to learn by building a real playable game.

The game has a retro 1990s computer-style design and includes 5 different stages: Beginner, Easy, Normal, Fast, and Challenge.

Players control the snake using Arrow keys, WASD, or touch buttons. The objective is to eat apples and increase your score. Every apple gives exactly 1 point.

The Challenge Stage adds obstacles to the game, making it more challenging while keeping the game playable.

Features

- 🐍 Classic Snake gameplay
- 🎮 5 stages with different difficulties
- 🍎 1 point for every apple
- 🚧 Challenge stage with obstacles
- 📱 Touch controls
- ⌨️ Keyboard controls
- ⏸️ Pause and restart
- 🏆 Saved best score
- ⚙️ Speed, sound, grid, and control options
- 🗄️ Local game database and game history
- 📊 Score, apples, stage, result, and game time tracking
- 📁 Export game history
- 🕹️ Retro arcade-style interface

The game saves its history and settings locally on the player's phone or browser.
