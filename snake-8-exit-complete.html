ABOUT SNAKE

THABO GAME - Retro Arcade Edition

Developed by: Thabo Seshoka

Email: seshokathabo747@gmail.com

This Snake game was developed by Thabo Seshoka as a programming project and a way to learn by building a real playable game.

The game is inspired by classic Snake games and uses a simple retro 1990s computer style.

How the game works: Choose a stage, control the snake, eat apples and build your score. Every apple gives exactly 1 point.

Challenge Stage: Four square obstacle boxes are placed around the board. They are the only extra obstacles added to the stage. The stage remains playable and you can still reach apples and earn scores.

Features: 5 stages, scoring, touch controls, keyboard controls, pause, restart, options, saved high score and a local game database.
